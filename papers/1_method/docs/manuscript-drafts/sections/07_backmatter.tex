\section*{Data and code availability}

All code needed to reproduce the study is openly available. The analysis pipeline that generates the figures, together with the simulation configurations that define every run, is deposited in a public repository (\texttt{macroir-validity}) and archived at Zenodo, with the DOI issued on acceptance. The simulation and inference engine is the \texttt{macro\_dr} software \cite{moffatt2025macroir}, referenced at the pinned version that produced the deposited data; each output file records the engine commit hash that generated it. No experimental data were used: every dataset in the paper is simulated, and is regenerable from the deposited configurations up to the simulation seed, which was not recorded for the original freeze (Materials and methods); the later differenced-Fisher battery injects an explicit seed through its deposited configuration (Supplementary File~1). % NOTE (LM): confirm the public repo name/URL and mint the Zenodo DOI at submission.

A separate library, \texttt{macroir}, carries the boundary-conditioned likelihood, its score, its Gaussian Fisher information and the distortion diagnostic of this paper out of the engine and into a small self-contained C++ core, with an R package and a Python package over it; the diagnostic returns the distortion matrix, its eigenvalue spectrum and the first-order bias from one call in either language. % src: macroir bindings/python/src/macroir_module.cpp:312 (distortion) ; bindings/r/NAMESPACE:21 (macroir_distortion), verified 2026-08-25 The scope of that library is narrower than the paper: it implements the boundary-conditioned member, the exact simulator and a Gauss-Newton fit, and it does not implement least squares, the open-loop member or the recursive member on instantaneous samples, so the comparisons reported here are reproducible only from \texttt{macro\_dr}. The core was transcribed from the engine and checked against it on eight cells, covering four kinetic schemes, three acquisition intervals spanning a factor of a hundred, a protocol whose concentration jumps split sampling intervals, and a recording with a gap, agreeing on the total log-likelihood to between $10^{-16}$ and $6\times10^{-15}$ relative and on the score to between $8\times10^{-14}$ and $1.4\times10^{-9}$. % src: macroir/docs/status.md ("What it is checked against", checkpoint cells and tolerances)
The two language packages are bindings over that one core rather than independent reimplementations, and they were run against it once on a single cell, by \texttt{tools/cross\_language\_check.py}, which is the evidence for the statement that the three interfaces return the same numbers. % src: macroir/tools/cross_language_check.py (one cell: scheme_CO, one parameter vector, one protocol, one seed)
